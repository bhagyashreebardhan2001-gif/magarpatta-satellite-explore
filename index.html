Magarpatta Vegetation Viewer

A satellite-based tool for monitoring vegetation cover in Magarpatta using Google Earth Engine.

Project Overview

This project provides an interactive web application built on Google Earth Engine to visualize and analyze vegetation cover in the Magarpatta study area. Users can select between multiple satellite datasets, define custom date ranges, filter by cloud cover, and view NDVI-based vegetation trends over time.

Datasets Used

  • Sentinel-2 (SR, Harmonized) — European Space Agency (ESA)
  • Landsat 9 (Level-2, Surface Reflectance) — USGS / NASA
  • MODIS NDVI (MOD13Q1) — NASA LP DAAC

Study Area

Magarpatta, Pune, Maharashtra, India
