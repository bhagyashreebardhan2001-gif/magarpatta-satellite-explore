# Thesis Satellite Explorer

## Project Purpose
This project presents the **Magarpatta Vegetation Viewer**, an interactive Google Earth
Engine web application developed to visualize and monitor vegetation cover within the
Magarpatta study area. The tool allows users to select a satellite dataset, define a
custom date range, filter imagery by cloud cover percentage, and generate an NDVI-based
time series to track vegetation health and change over time. This repository hosts the
supporting documentation and landing page for the thesis project.

## Datasets
| Dataset | Source | Description |
|---|---|---|
| Sentinel-2 (SR, Harmonized) | European Space Agency (ESA) | True-colour composite imagery |
| Landsat 9 (Level-2, Surface Reflectance) | USGS / NASA | True-colour composite imagery |
| MODIS NDVI (MOD13Q1) | NASA LP DAAC | Vegetation index time-series analysis |
